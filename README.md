# Customer Behaviour Analysis

## Overview
Customer Behaviour Analysis is an end-to-end data analytics project focused on understanding customer purchasing patterns, spending behavior, and business trends. The project uses Python for data analysis, SQL for querying data, and Power BI for interactive dashboard creation.

## Dataset
The dataset contains customer demographic information, purchase history, transaction details, product categories, and spending data.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PostgreSQL / MySQL / SQL Server
- Power BI
- Gamma AI

## Project Workflow

### 1. Data Loading
- Imported dataset using Python.
- Loaded data into Pandas DataFrame.

### 2. Exploratory Data Analysis (EDA)
- Analyzed customer demographics.
- Identified spending patterns.
- Examined purchase trends.
- Created visualizations and summary statistics.

### 3. Data Cleaning
- Removed duplicates.
- Handled missing values.
- Corrected data types.
- Standardized data formats.

### 4. SQL Analysis
Performed business-related SQL queries:
- Total Revenue
- Total Customers
- Top Customers
- Popular Product Categories
- Monthly Sales Trends
- Customer Segmentation

### 5. Power BI Dashboard
Built an interactive dashboard showing:
- Revenue Analysis
- Customer Segmentation
- Product Performance
- Sales Trends
- Key KPIs

### 6. Report Creation
Prepared a business report summarizing:
- Key Findings
- Insights
- Recommendations

### 7. Presentation
Created a professional presentation using Gamma AI to communicate project findings and business insights.

## Dashboard Features

## Key Insights
- Identified high-value customers.
